# 📊 Dashboard - Clientes Adicionados

Dashboard interativo para visualização e análise de clientes adicionados durante a feira de filamentos.

## 🎯 Funcionalidades

- 📈 **Data Science Analytics**: 4 gráficos automatizados com insights
- 📱 **Mobile Responsive**: Interface otimizada para celular
- 💬 **WhatsApp Integration**: Envio em massa com intervalos de 5 segundos
- 🖼️ **Upload de Imagem**: Drag & drop com preview
- 🔍 **Busca Inteligente**: Filtro por cliente, usuário ou dados
- 📊 **Métricas em Tempo Real**: 96.6% de qualidade de dados

## 🚀 Como Usar

1. Abra `dashboard.html` no navegador
2. Visualize os clientes por colaborador
3. Use os botões de transmissão para envio em massa
4. Analise os gráficos de Data Science

## 📱 Contato via WhatsApp

- **Individual**: Botão em cada card de cliente
- **Em massa**: Botão de transmissão por colaborador
- **Global**: Botão para todos os 113 clientes válidos
